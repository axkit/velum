# logw пишет упавшие запросы на уровне DEBUG

Оценка: ≈ 1 час (правка `level()` и вызовов, тест на уровень).

`Wrapper.level(dur)` повышает уровень только для медленных запросов (WARN), всё остальное, включая запросы
с ошибкой, идёт в DEBUG. На проде с уровнем INFO упавший запрос не виден. Нужно: `err != nil` →
`slog.LevelError` во всех `emit*`. Согласовано владельцем 24.11.2026.
